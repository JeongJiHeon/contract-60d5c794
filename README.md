# Hello Greeting Service - 서비스 계약서

## 프로젝트 개요
**Hello Greeting Service**는 사용자에게 맞춤형 인사 메시지를 제공하는 웹 기반 서비스입니다.

- **프로젝트 ID**: 60d5c794-fc22-41c5-a9ec-549711d5f003
- **서비스 이름**: Hello Greeting Service
- **버전**: 1.0.0
- **작성일**: 2025-10-29

## 📄 문서
전체 서비스 계약서는 [`SERVICE_CONTRACT.md`](./SERVICE_CONTRACT.md) 파일을 참조하세요.

## 🎯 주요 기능
1. **AI 기반 인사 메시지 생성**: GPT-4를 활용한 맞춤형 인사
2. **다국어 지원**: 한국어, 영어, 일본어, 중국어
3. **시간대별 인사**: 아침, 점심, 저녁, 밤 자동 변경
4. **메시지 히스토리**: 과거 인사 메시지 조회 및 관리
5. **사용자 맞춤 설정**: 선호 언어, 톤, 테마 설정
